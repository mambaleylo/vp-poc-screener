# VP-POC Screener

Скринер сигналов на основе логики индикатора **Bar Magnified Volume
Profile/Fixed Range [ChartPrime]** (TradingView): строит fixed-range
volume profile по окну баров, находит зоны с самым большим объёмом
(POC + HVN), и даёт LONG/SHORT сигнал, когда цена вонзается в такую
зону фитилём и закрывается обратно наружу — то есть отбивается от
объёмной поддержки/сопротивления.

Это отдельный проект, только сигналы/алерты — без авто-трейдинга.
Данные — публичное REST API Gate.io USDT-M фьючерсов (ключи не нужны).

## Запуск (Termux)

```bash
pip install -r requirements.txt
python vp_poc_screener.py
```

Открой `http://127.0.0.1:8080` в браузере телефона.

## Как это работает

1. Раз в `VP_SCAN_INTERVAL` секунд (по умолчанию 45) берётся вселенная
   пар (USDT-фьючерсы Gate.io, отфильтрованные по 24ч объёму
   `VP_MIN_VOL_USD`, топ `VP_MAX_SYMBOLS` по объёму).
2. Для каждой пары тянутся последние `VP_LOOKBACK` свечей (таймфрейм
   `VP_INTERVAL`, по умолчанию 15m — как в демо-скринах автора индикатора).
3. Строится volume profile: диапазон [lowest_low, highest_high] бьётся
   на `VP_SEGS` сегментов (как в Pine-скрипте), объём каждой свечи
   распределяется по сегментам пропорционально перекрытию её
   high-low диапазона с каждым сегментом.
4. Топ-`VP_HVN_TOP_N` сегментов по объёму объединяются в зоны (HVN),
   самая объёмная зона = POC.
5. Сигнал: последняя закрытая свеча коснулась зоны (low/high вошли в
   диапазон зоны), а закрытие — снаружи зоны в ту же сторону, что и
   закрытие предыдущей свечи (то есть цена подошла и отбилась, а не
   пробила насквозь).
6. Сигналы дедуплицируются по (символ, зона) с cooldown
   `VP_COOLDOWN` секунд, чтобы не спамить одним и тем же уровнем.
7. Опционально — алерт в Telegram (см. переменные окружения ниже).

## UI

- **Сигналы** — лента сработавших LONG/SHORT сигналов.
- **Watchlist** — все отслеживаемые пары, отсортированные по
  расстоянию до ближайшей объёмной зоны (% от цены) — видно, что
  подходит к уровню ещё до срабатывания.
- Тап по строке открывает чарт: свечи + профиль объёма справа + линии
  зон (canvas, без внешних CDN — работает офлайн-совместимо).

## Переменные окружения (все опциональны)

| Переменная          | По умолчанию | Что делает                                  |
|---------------------|--------------|----------------------------------------------|
| `VP_PORT`           | 8080         | порт HTTP-сервера                             |
| `VP_SEGS`           | 100          | число сегментов профиля                       |
| `VP_LOOKBACK`       | 100          | число свечей в окне                           |
| `VP_INTERVAL`       | 15m          | таймфрейм свечей                              |
| `VP_HVN_TOP_N`      | 6            | сколько топ-сегментов объединять в зоны       |
| `VP_MIN_VOL_USD`    | 500000       | мин. 24ч объём для попадания во вселенную     |
| `VP_MAX_SYMBOLS`    | 150          | сколько пар максимум сканировать              |
| `VP_SCAN_INTERVAL`  | 45           | пауза между циклами сканирования, сек         |
| `VP_COOLDOWN`       | 900          | антиспам на один и тот же сигнал, сек         |
| `VP_WORKERS`        | 8            | потоков для параллельного скана               |
| `VP_TG_TOKEN`       | -            | токен Telegram-бота для алертов               |
| `VP_TG_CHAT`        | -            | chat_id для алертов                           |

## Дальнейшие шаги (не реализовано)

- Авто-трейдинг на Gate.io по этим сигналам (как в EMA-screener /
  WickFill / SMC Optimizer) — можно добавить отдельным модулем по
  аналогии, когда решишь подключать реальные ордера.
- Бэктест сигналов на истории для оценки винрейта перед торговлей
  живыми деньгами.
