# Лаба: как восстановить данные

Данные лабы не хранятся в репозитории (гигабайты). Код — здесь, данные скачиваются заново:

- `dl_all.py` — 1h-свечи всех USDT-M фьючерсов Binance (зеркало data.binance.vision на S3, 2021-01 … 2026-09) в `data/1h/<SYM>.csv`
  (t, o, h, l, c, объём в $). Запуск из папки, где будет `data/1h`.
- `common.py` — бот для тестов и лабы: копия бота во временной папке, модели и список бэктеста из репозитория.
- `rp.py` — прогон кода бота ⚡ (dlm_scan + dlm_settle, виртуально) по 2026 на скачанных свечах: группы монет base / new150 / new50.
- `money200.py`, `lev.py`, `path200.py` — деньги связки по спискам бэктеста бота (риски модулей, лимит риска 90%, маржа и плечо).
- `vol.py`, `quiet.py` — волатильность по годам (Coin Metrics), годы без ⚡.

Утеряны с перезапуском контейнера (не были в git): движки s21h2_engine, s19h_engine, lv_engine, ev2/ev3_engine, lv_wf, lgbpure,
bt_trades и данные исследований (оценки моделей, пулы). Всё новое коммитится сюда сразу.
