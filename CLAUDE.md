# Правила для Claude в этом репозитории

- Все ответы пользователю — только на русском языке. Таблицы, итоги, пояснения, вопросы — тоже на русском. Английский — только в коде, комментариях к коду и сообщениях коммитов.
- Перед каждым пушем — объяснение и таблица сравнения; изменения, влияющие на деньги, — только после согласия пользователя, с честными расчётами.
- Любой долгий фоновый процесс (расчёты лабы и т.п.) — сразу ставить под наблюдение с проверкой каждую минуту (Monitor): сигнал при падении, зависании (процессор не растёт) и окончании; не оставлять пользователя ждать вслепую. Команды ожидания не должны находить сами себя (pgrep -f по своему же тексту).
